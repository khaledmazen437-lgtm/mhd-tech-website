# MHD Tech — Company Website

> الموقع الرسمي لـ MHD Tech — خدمات البرمجة، الدبلومات التعليمية، وتفاصيل كل دبلوم.

The official MHD Tech website: services (full-stack, frontend, backend, mobile), educational diplomas with per-diploma detail pages, and an about page.

## Features

- Services and diploma catalog driven by `src/data.jsx`
- Dedicated diploma details pages
- React SPA with Vite build

## Tech Stack

- React + Vite, Tailwind CSS, deployed on Vercel (`vercel.json`)

## Running

```bash
npm install
npm run dev
```

Build for production with `npm run build`.
